# Oshi theater

Knowledge base for a fan-made watch-together window for VTuber livestreams. Built by Krischan's team.

**The short version:** fans want to feel like they're sitting next to their friends while they watch their oshi, without a voice call or another chat to keep up with. The product is a small two-screen window, styled after the Nintendo DS settings screen, that floats beside the stream: the top screen shows the theater and the crowd, the bottom screen shows your party up close. It launches browser-first in the Philippines, with a browser extension as the upgrade.

The product has no name yet. "Oshi theater" is only this repository's name.

## Starting a new session

- **Claude (claude.ai or the Claude app):** start the chat with: "We're working on the oshi theater knowledge base in `s-ging/oshi-theater-info`. Pull it and read AGENTS.md before anything else."
- **Claude Code on your computer:** clone the repo, open a terminal in it and run `claude`. `CLAUDE.md` loads automatically.
- **Other AI tools (Cursor, Codex and similar):** open the repo; they read `AGENTS.md`.
- **Chatbots without repo access:** paste `AGENTS.md` and `project/status.md` at the start.

Every session ends by committing and pushing its changes.

No plain-text passwords or keys; see [AGENTS.md](AGENTS.md#credentials).
