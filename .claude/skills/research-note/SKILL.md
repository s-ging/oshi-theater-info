# Research note

1. Copy `templates/research.md` to `research/YYYY-MM-DD-short-topic.md`. Put screenshots and source files in `research/files/` with the same date prefix.
2. Start with a **Method** line: what was looked at and how (sites read, searches, tests, files or screenshots from the team).
3. Write findings in your own words. Give every fact its source (a link with the date read, "Krischan said", "team screenshot") and mark guesses and estimates as such.
4. End with **What this means for the project** and **Next steps**.
5. Update the files this changes: `product/` for the product, `project/open-questions.md` for new questions, `project/status.md` if priorities moved.
6. Add a row to `research/README.md`.
7. Finish with the `session-log` skill.

Keep quotes from sources short; summarize instead of copying.
